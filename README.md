# pet-projects

个人小型项目合集：一个项目一个文件夹，各自独立，互不依赖。

| 项目 | 一句话 | 入口 |
| --- | --- | --- |
| [gnome-theme](gnome-theme/) | Arctic Ink —— Arch Linux + GNOME 51 的冷调深色桌面方案 | [install.sh](gnome-theme/install.sh) · [README](gnome-theme/README.md) |

## 约定

- 一个项目一个文件夹，文件夹内自带 README，能单独拷走使用。
- 备份、日志、本机配置不进仓库（见 `.gitignore`）。
- 项目之间不共享代码，改一个不会影响另一个。
